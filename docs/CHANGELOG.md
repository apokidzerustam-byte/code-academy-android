# CHANGELOG

## 0.0.4-proto — 2026-11-19 (этап 4: анимированные уроки)
- Плеер урока на вкладке «Урок»: код набирается на экране, подсвечиваются строки, запуск и вывод в консоли,
  сообщения об ошибках красным, заметки; синхронно с озвучкой каждой сцены.
- Озвучка голосом автора: content-pipeline/narrate.py + workflow «Narrate lessons» (Chatterbox, проверка каждой
  фразы распознаванием faster-whisper, пересинтез при ошибке, AAC по сценам, тайминги фраз, субтитры WebVTT).
- Субтитры, скорость, перемотка, переход по сценам, пауза при сворачивании, продолжение с сохранённого места.
- Сценарий: действие output со stream=stderr (ошибка), привязка действия к фразе озвучки (cue); валидатор
  сверяет текст ошибки с реальным запуском и проверяет озвучку (сцены, файлы, тайминги, устаревший текст).
- Постоянный ключ подписи прототипа и номер сборки в versionCode: новые версии ставятся поверх.
- Терминал: вставка нескольких строк выполняет их по очереди.

## 0.0.3-proto — 2026-11-18 (этап 3: IDE)
- Редактор CodeMirror 6 в экране задания и в IDE; панель символов; запасной простой редактор (настройка).
- «Мои проекты»: проекты из нескольких файлов и папок, автосохранение, сохранение при выходе.
- Запуск проекта в уровнях A и W: свои модули, ввод, файлы, созданные программой, синхронизируются обратно.
- Учебный терминал внутри проекта.
- Исправления по независимому аудиту: текст редактора отправляется без задержки (Запуск/Проверка видят последнюю правку);
  редактор и терминал заблокированы во время выполнения; файлы проверяются до удаления старых; символические ссылки
  не читаются и не удаляются по ним; файловые операции — не в главном потоке; конфликт «файл/папка с одним именем»
  отклоняется; режим B явно сообщает, что проекты не поддерживаются; уникальные id проектов.
- Исправлен краш экрана IDE при первом открытии (ранний return внутри Column).
