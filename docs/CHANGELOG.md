# CHANGELOG

## 0.0.9-proto, обновление — 2026-11-22 (скорость и качество нейросетевого наставника)
- Ответ лёгкого режима показывается сразу, пока модель считает; ответ нейросети подставляется по законченным предложениям;
  под ответом — разбивка времени (загрузка модели, запрос и токены из кэша, скорость ответа).
- Запрос короче и переписан (обращение на «ты», без пересказа разделов), кэш начала запроса, потоки по быстрым ядрам,
  длина ответа по виду запроса, оборванный ответ обрезается до предложения.
- Новые модели: Qwen3-4B-Instruct-2507 (лучшие ответы) и Qwen3-1.7B; ссылки на загрузку закреплены на ревизии репозитория.
- «Проверить нейросеть»: время по этапам, токены запроса и из кэша, скорость, число быстрых ядер, инструкции процессора
  (DOTPROD, MATMUL_INT8…) и предупреждение, если быстрых инструкций нет.
- Модель держится в памяти 10 минут (было 3), при нехватке памяти выгружается сразу.
- Защита от решения: ловится строка решения, записанная другим синтаксисом (конкатенация вместо шаблона).

## 0.0.9-proto — 2026-11-22 (этап 9: ИИ-наставник)
- Лёгкий наставник (всегда работает, без сети): разбор ошибок Python/JavaScript/SQL по-русски со ссылкой на урок,
  лестница подсказок (намёк → направление → концепция → где искать → алгоритм → решение только кнопкой после попытки),
  поиск по конспектам и частым ошибкам, упражнения по слабым навыкам, советы по структуре проекта.
- Защита от выдачи решения: любой ответ (правила, конспекты, нейросеть) проверяется по эталону задания; «предскажи результат»
  ответ не называется ни строкой, ни прозой. Эталон в запрос модели не передаётся.
- Нейросетевой режим (по желанию): llama.cpp + Qwen2.5-Coder 0.5B/1.5B (Q4_K_M, Apache 2.0), отдельный процесс :mentor,
  работа в фоне, ограничение длины, остановка при перегреве, код ученика никуда не отправляется.
- Установка модели без интернета в приложении: ученик скачивает файл в браузере, выбирает его в настройках, приложение проверяет
  формат GGUF и SHA-256 и копирует в приватную папку.
- Панель «Наставник» в заданиях, этапах проектов и IDE; быстрые кнопки «Подсказка», «Почему ошибка?», «Объясни тему».
- Независимый аудит (другая модель): исправлены обход защиты (регистр, обратные кавычки, переименования, проза в «предскажи»),
  гонки в нативном слое, обработка ошибок JNI, ложные срабатывания классификатора, раннее раскрытие подсказок.

## 0.0.7-proto — 2026-11-22 (этап 7: HTML/CSS/JS, SQL, FastAPI, Kotlin)
- Веб-раннер (одна невидимая WebView): HTML/CSS/JS ученика — в iframe с sandbox и строгой CSP (сети нет),
  циклы JavaScript останавливаются через 2 с с понятной ошибкой, синтаксические ошибки — по-русски с номером строки,

  неверные значения, пропущенная «;»). Предпросмотр страницы в задании и в IDE.
- SQL: SQLite (sql.js) в воркере, новая база на каждый запуск, таблица результата, ошибки с номером строки;
  зависший запрос останавливается по таймауту. В проектах schema.sql выполняется перед запросом.
- Kotlin: на телефоне — проверка синтаксиса и структуры (функции, типы, классы, конструкции); запуск — через
  GitHub Actions (шаблон проекта Kotlin со сценарием сборки и инструкцией), экспорт проекта в ZIP.
- FastAPI в режиме A (Chaquopy: fastapi 0.125.0, pydantic 1.10.27, httpx 0.28.1): задания проверяются запросами
  TestClient без сети (код ответа и JSON). Исправлено: предзагрузка `_asyncio` раньше `asyncio` ломала
  `asyncio.current_task()` (FastAPI падал на `set_name`).
- Новые уроки: «HTML и CSS: первая страница», «JavaScript: функции, циклы и кнопки», «SQL: первые запросы SELECT»,
  «FastAPI: первый веб-API», «Kotlin: первые шаги» — по 5 заданий (написать / исправить / предсказать).
- Валидатор: HTML/JS/SQL/Kotlin проверяются тем же веб-раннером в Chrome, Kotlin — настоящим kotlinc
  (компиляция эталонов и вывод сцен), FastAPI — на CPython; режим `--no-run` для коммита озвучки.
- Тест на устройстве для каждого языка: запуск, ошибка, остановка, автопроверка всех заданий новых пакетов.
