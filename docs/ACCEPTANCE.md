# Приёмка по ТЗ (этап 10)

Обновлено: 2026-11-22. Это честная матрица: что выполнено и чем проверено, что реализовано без проверки на устройстве, чего нет.
Правило 20 ТЗ: функция не называется готовой без фактического тестирования. «Проверено» ниже — это автоматические тесты в CI
(JVM, эмуляторы Android 10 и 14, настоящие модели на Linux) и аудит APK; **ручная приёмка на телефоне заказчика не проведена** — кроме
нескольких проверок наставника (см. TEST_REPORT), поэтому раздел «Ручная приёмка» в конце — список для заказчика.

## Критерий MVP (раздел 18 ТЗ)
Новый пользователь устанавливает приложение, начинает без аккаунта, открывает урок, смотрит видео, пишет и запускает код, решает задание,
получает проверку, исправляет ошибку, завершает урок, видит обновлённый прогресс и после закрытия приложения продолжает с того же места.

| Требование MVP | Статус | Чем подтверждено |
| --- | --- | --- |
| Главная и навигация | Проверено | UI-тест сквозного сценария (API 29/34) |
| Структура курса | Проверено (структура); **содержимое — не полное** | Экран «Программа» показывает 15 этапов; уроки есть не во всех |
| Первые 10 полноценных уроков | Проверено | 10 уроков Python: валидатор (эталоны проходят, 80+ типовых ошибок ловятся), прохождение на устройстве в раннерах A и W |
| Русские видео и субтитры | Проверено в форме, согласованной с заказчиком | Анимированные уроки (не MP4) с озвучкой голосом автора и субтитрами; плеер — UI-тест на API 29/34 |
| IDE, консоль, запуск, остановка | Проверено | Тесты раннеров (таймаут, «Стоп», восстановление), UI-тест IDE; «Стоп» в самом UI IDE — только в тестах раннеров |
| Локальный Python | Проверено | Pyodide (W) и Chaquopy (A), эмуляторы |
| Автопроверка, задания, подсказки | Проверено | Видимые и скрытые тесты; 6 ступеней подсказок (UI-тест — 1-я ступень) |
| Прогресс, статистика, повторение | Проверено | JVM на фиксированных историях + UI-тесты |
| Офлайн | Проверено | В APK нет `INTERNET` (aapt2 в каждой сборке, аудит); тест на устройстве считает байты сети |
| Экспорт проектов | Проверено | ZIP-экспорт/импорт (JVM); выбор файла на телефоне — не проверен вручную |
| Продолжение с того же места после закрытия | Проверено частично | Пересоздание Activity и черновики — тесты; «убить процесс и открыть заново» на телефоне — не проверено |
| Всё на Android | Проверено на эмуляторах API 29 и 34 | Реальный телефон: Red Magic 8 Pro (Android 14) — наставник и общие экраны, не весь сценарий |

Вывод: технический критерий MVP выполнен на материале пилота (10 уроков Python + 5 уроков других языков); полный курс (ниже) — нет.

## Тестирование и приёмка (раздел 19 ТЗ)
| Требование | Статус | Комментарий |
| --- | --- | --- |
| Каждый экран и кнопка, без фиктивных | Частично проверено | UI-тесты покрывают главные сценарии и экран настроек (этап 10); не каждая кнопка. Заглушек и имитации запуска нет: запуск выполняют настоящие раннеры |
| Образовательная проверка (понятность, последовательность, адаптация) | Не проведена независимо | Уроки читал только автор; пробного обучения с живыми учениками не было |
| Безопасность исполнения, изоляция файлов, остановка, секреты, сеть | Проверено с оговорками | Раннеры W и A, таймауты, «Стоп»; секреты не в APK (аудит); **уровень A — не граница безопасности**, уровень B невозможен со стандартным Chaquopy; ключ прототипа публичен (RELEASE.md) |
| Время запуска | Замер на эмуляторе в CI | Холодный старт, медиана 5 запусков: 0,91 с (API 34) и 1,03 с (API 29), debug-сборка, эмулятор без GPU; ориентир ТЗ-плана ≤ 2 с. **На телефоне не измерено** |
| RAM | Замер на эмуляторе (PSS после запуска) | 79–84 МБ после холодного старта (эмулятор). На телефоне не измерено; нейросеть: загрузка модели 4B отдельным процессом, выгрузка при нехватке памяти (JVM-логика) |
| Нагрев, батарея | **Не проверено** | Нужны замеры на телефоне; режим «Экономичный» уменьшает нагрузку наставника, но эффект не измерен |
| Слабые устройства | Частично | Эмулятор API 29 (4 ГБ); модели 0.5B/1.7B для слабых телефонов; на реальном слабом устройстве не проверялось; API 26–28 не тестировались |
| Восстановление после нехватки памяти | Частично | Нейросеть в отдельном процессе (падение не роняет приложение, запись в журнал сбоев), `onTrimMemory` — JVM-логика; настоящая нехватка памяти на устройстве не воспроизводилась |
| Работа без интернета | Проверено | см. выше |

Приёмка («программа от нуля, практика после каждого урока, реальная IDE, запуск поддерживаемых языков, автопроверка, офлайн, бесплатность,
безопасность, Android»):
- Программа от нуля — **только пилот** (первые 10 уроков Python и вводные уроки по HTML/CSS/JS, SQL, FastAPI, Kotlin).
- Практика после каждого урока — есть во всех существующих уроках (37 + 25 заданий, 4 мини-проекта, сквозной проект: 2 этапа).
- Запуск языков: Python, HTML/CSS/JS, SQL, FastAPI — выполняются на устройстве; **Kotlin — синтаксис и структура на телефоне, поведение — GitHub Actions** (нет JVM).
- Бесплатность: нет аккаунтов, платежей, рекламы; зависимости MIT/Apache/PSF/MPL (docs/LICENSES.md).

## Производительность и режимы (раздел 15 ТЗ)
- Режимы «экономичный / стандартный / расширенный» реализованы для нейросетевого наставника (потоки, предзагрузка, время удержания модели, длина ответа);
  логика и сохранение настройки проверены (JVM, UI-тест); **эффект на нагрев и батарею не измерен**.
- Ленивая загрузка, кэширование (кэш начала запроса, предзагрузка), нейросеть в отдельном процессе, восстановление состояния (черновики, продолжение урока) — реализованы и протестированы.
- Минимальная версия Android: **26** (Python 3.13 и 64-битные библиотеки); фактически проверены API 29 и 34 (эмулятор) и Android 14 (телефон).

## Что должен проверить заказчик на телефоне (ручная приёмка)
1. Установить по [USER_GUIDE.md](USER_GUIDE.md), пройти урок 1 до конца (видео → код → проверка), закрыть приложение смахиванием, открыть — продолжить с того же места.
2. Пройти ещё 2–3 урока и задание с ошибкой: подсказки, повторение на следующий день.
3. Настройки → «Данные и резервная копия» → сохранить копию в «Загрузки», удалить приложение, установить заново, восстановить.
4. Наставник с моделью: время ответа, нагрев после 10 вопросов подряд; сравнить режимы «Экономичный» и «Стандартный».
5. Включить авиарежим и проверить, что всё работает.
6. Если приложение закрылось: Настройки → Журнал сбоев → «Поделиться».
