## Известные ограничения прототипа
- Нейросеть 0.5B иногда отвечает неточно или не по-русски — такие ответы заменяются лёгким режимом; ответы модели
  помечены «проверяйте её советы».
- Наставник не пересказывает подсказку 5 («алгоритм») и другие, почти раскрывающие решение, — их открывает кнопка.
- Веб-языки (HTML/CSS/JS, SQL, Kotlin) требуют WebView с WEB_MESSAGE_LISTENER; на старом WebView недоступны.
- Kotlin на телефоне не компилируется — проверяются синтаксис и структура, поведение — только в CI/на компьютере.
- Уровень A не является границей безопасности (обход через интроспекцию возможен) — задокументировано.
- Нет лимита памяти для Python (RLIMIT_AS несовместим с ART); защита — гибель процесса раннера, а не приложения.
- Клиентский таймаут уровня A не убивает зависший процесс (только отвязывается); основной механизм — сторожевой таймер в раннере.
- Уровень B пока без доступа к файлам проекта.
- Релизный APK подписан debug-ключом.
