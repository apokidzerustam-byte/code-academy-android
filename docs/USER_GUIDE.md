# Руководство ученика

Для телефона на Android 8.0 и новее (minSdk 26). Приложение бесплатное, без аккаунта и без интернета: после установки сеть не нужна.
Только скачивание необязательной модели наставника идёт через браузер телефона.

## 1. Установка и обновление
1. Откройте на телефоне страницу https://github.com/apokidzerustam-byte/code-academy-android/releases (войдите в GitHub),
   найдите черновик «Прототип (последняя сборка)» и нажмите на файл `code-academy-proto.apk` (около 180 МБ — с озвучкой уроков,
   лучше по Wi-Fi). Если браузер спросит, разрешите скачивание. Черновик видит только владелец репозитория; он заменяется
   новой сборкой после каждой проверки на `main`.
2. Откройте скачанный файл (уведомление «Загрузка завершена» или приложение «Файлы» → «Загрузки»).
3. Android попросит разрешить установку из этого источника (браузера или «Файлов»): разрешите, вернитесь назад и нажмите «Установить».
4. Обновление — те же шаги по той же ссылке: новая версия ставится поверх старой, прогресс и проекты сохраняются.
   Версия указана внизу экрана «Настройки» (раздел «О приложении»).
5. Чтобы убедиться, что файл не повреждён, сравните контрольную сумму: в том же черновике рядом лежит `SHA256SUMS.txt`.

Если Android пишет «приложение не установлено, конфликт с существующим пакетом» — на телефоне стоит версия, подписанная другим ключом.
Перед удалением сохраните резервную копию (раздел 6): удаление приложения стирает данные. Подробности про ключи — [RELEASE.md](RELEASE.md).

## 2. Как учиться
- **Главная:** «Начать/Продолжить» открывает следующий урок; ниже — прогресс, повторения на сегодня, слабые темы, план на сегодня.
- **Программа** — все этапы и уроки; **Проекты** — мини-проекты и сквозной проект; **Статистика**; **Карта знаний**; **План** (минут за занятие
  и дней в неделю); **Повторение** (задания по слабым навыкам в нужный день).
- **Урок:** анимированный сценарий с озвучкой (пауза, скорость 0,75–2×, перемотка по сценам, субтитры), затем конспект и задания.
- **Задание:** условие, редактор кода, «Запустить», «Проверить», подсказки по ступеням (от намёка до решения; решение — только после попытки).
  Код сохраняется сам, даже если приложение закрылось.
- **IDE** (из проекта): файлы и папки, консоль с кнопкой «Стоп», ввод для программы, учебный терминал (`ls`, `cd`, `cat`, `python` …).
- Результат урока считается, когда задание проверено; следующая практика назначается по интервалам 1, 3, 7, 14, 30 дней.

## 3. Настройки
- **Тема** (как в системе / светлая / тёмная), **размер текста**.
- **Выполнение кода:** автоматически (изолированный режим, при недоступности — ограниченный), только изолированный, только ограниченный.
  Изолированный режим безопаснее; ограниченный нужен для тем с потоками, asyncio и сервером FastAPI.
- **Редактор:** с подсветкой (CodeMirror) или простое поле ввода — если редактор тормозит.
- **Режим производительности** (работает для ИИ-наставника):
  | Режим | Когда выбирать |
  | --- | --- |
  | Экономичный | слабый телефон, мало заряда: 2 потока, ответы короче, модель выгружается через 2 минуты простоя, заранее не загружается |
  | Стандартный | по умолчанию: 4 потока, модель загружается при открытии панели наставника и держится 10 минут |
  | Расширенный | мощный телефон, хочется подробнее: ответы длиннее, модель держится 30 минут (больше памяти и батареи) |
- **Журнал сбоев, резервная копия** — разделы 5 и 6.

## 4. ИИ-наставник
- **Лёгкий режим работает всегда:** разбор ошибок Python/JavaScript/SQL по-русски, лестница подсказок, поиск по конспектам.
  Он не требует скачивания и не отправляет данные никуда.
- **Нейросеть (по желанию):** отвечает связнее, но медленнее и всегда может ошибиться — проверяйте советы. Решение задания наставник не выдаёт.
  1. Настройки → ИИ-наставник → выберите модель (для Red Magic 8 Pro подходит Qwen3 4B Instruct 2507: около 15–25 с на ответ;
     если медленно или телефон греется — Qwen3 1.7B).
  2. «Как установить»: скачайте файл модели в браузере (1–2,5 ГБ, по Wi-Fi) по кнопке «Открыть в браузере».
  3. «Выбрать файл модели» → файл из «Загрузки». Приложение проверит контрольную сумму и скопирует модель к себе; файл в «Загрузках» можно удалить.
  4. Включите «Нейросетевой режим», нажмите «Проверить нейросеть»: покажет время по этапам и скорость.
- Без темы, урока, кода или ошибки модель не запускается: ответит лёгкий режим и подскажет, что ввести.

## 5. Если приложение закрылось само
Настройки → **Журнал сбоев**: здесь сохраняется причина (время, версия, устройство, процесс, стек ошибки). Журнал хранится только на телефоне.
«Копировать» или «Поделиться» — передать разработчику; «Очистить журнал» — удалить. Если нейросеть не хватило памяти, процесс наставника
завершается отдельно от приложения: обучение продолжится, ответит лёгкий режим, а в журнале появится запись.
Что помогает при нехватке памяти: режим «Экономичный», модель поменьше (1.7B или 0.5B), закрыть тяжёлые приложения.

## 6. Резервная копия и перенос на другой телефон
Настройки → «Данные и резервная копия»: «Сохранить копию» (файл `code-academy-backup-ДАТА.zip` — в «Загрузки» или на диск) и «Восстановить».
Копия содержит прогресс, попытки, навыки, повторения, проекты и настройки; перед восстановлением приложение проверяет файл и ничего не меняет,
если он повреждён или от другой версии. Делайте копию перед удалением и переустановкой приложения: «Удалить все данные» и удаление приложения стирают всё.

## 7. Частые вопросы
- **Редактор без подсветки.** На старом WebView (Android 10 и ранее без обновлений) включается простое поле; HTML/CSS/JS, SQL и Kotlin там недоступны —
  обновите «Android System WebView» в магазине приложений или через настройки устройства.
- **Нет звука урока.** Проверьте громкость мультимедиа; субтитры показываются всегда.
- **Нужно ли разрешение на интернет?** Нет: в приложении его нет, запросить сеть оно не может (проверяется при каждой сборке).
