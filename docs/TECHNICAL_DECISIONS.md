## Постоянный ключ подписи прототипа (2026-11-18)
Проблема: GitHub Actions подписывал APK debug-ключом, который создаётся заново на каждой машине CI.
У каждой сборки был свой сертификат, и Android отказывался ставить новую версию поверх старой
(у заказчика осталась версия этапа 1, без «Проектов»). Решение: постоянный ключ `signing/prototype.keystore`
в репозитории и versionCode = номер сборки CI. Ключ публичный — подходит только для прототипа;
для магазина приложений будет отдельный секретный ключ.

## Анимированные уроки: рендер в приложении + аудио по сценам (2026-11-19)
- Урок не видеофайл: приложение рисует сцену по scenario.json, звук — отдельный AAC-файл на сцену.
  Плюсы: размер (~1,5 МБ на урок вместо десятков МБ видео), текст кода можно копировать, тёмная тема,
  крупный шрифт, перемотка по сценам. Кадр вычисляется из времени (LessonTimeline) — перемотка тривиальна.
- Время плеера берётся из позиции MediaPlayer текущей сцены, поэтому анимация не уходит от голоса.
  Без озвучки урок идёт по таймеру (≈70 мс на символ текста) с субтитрами.
- Действия сцены растягиваются на длину речи; точная привязка — поле cue (номер фразы).
  Деление на фразы одинаково в Python (narrate.py) и Kotlin (LessonTimeline.splitPhrases), это проверяет тест.
- Качество синтеза контролируется автоматически: каждую фразу распознаёт faster-whisper, при ошибке > 22 %
  фраза синтезируется заново (до 3 попыток). Сравнение идёт в общей латинской записи («принт» = print).
- Аудио коммитится workflow в main; пересинтез только изменённых сцен (хэш текста, записи голоса и настроек).

## Чёткость и ударения озвучки (2026-11-19)
- Русская часть Chatterbox обучена на тексте с ударениями от russian_text_stresser, но без этого пакета
  ударения молча пропускались. Теперь ударения ставятся явно: автоматически (russian_text_stresser,
  numpy<2 из-за spaCy 3.6), затем поверх — словарь курса content-pipeline/pronunciation.json и поле stress сцены.
  Встроенная расстановка в Chatterbox отключается, чтобы не было двойных знаков (инструмент портит уже
  размеченные слова).
- Латинские термины читаются по словарю (print → «принт», SyntaxError → «си́нтакс э́ррор»): модель с меткой
  языка ru плохо читает латиницу.
- Каждая фраза синтезируется в 3 вариантах; выбирается самый разборчивый: 2·CER − средняя уверенность
  распознавания (avg_logprob). Опорная запись чистится (срез гула, шумоподавление, нормализация громкости).
  Параметры: exaggeration 0,45, cfg_weight 0,5, temperature 0,65 (спокойнее и чётче, чем по умолчанию).
- Workflow «Stress probe» за пару минут показывает текст, который получит синтезатор, — ударения
  проверяются до долгого синтеза.
