# HTML и CSS: первая страница

## Скелет
```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <title>Подпись вкладки</title>
</head>
<body>
  …то, что видно на странице…
</body>
</html>
```

## Основные теги
| Тег | Что это |
|---|---|
| `<h1>`…`<h6>` | заголовки |
| `<p>` | абзац |
| `<ul>`, `<ol>`, `<li>` | список (маркированный, нумерованный) и его пункт |
| `<a href="…">` | ссылка |
| `<img src="…" alt="…">` | картинка (одиночный тег) |
| `<button>` | кнопка |

Атрибуты: `имя="значение"` внутри открывающего тега. `id` — уникальное имя элемента, `class` — группа.

## CSS
```css
h1      { color: teal; }        /* все h1 */
.note   { font-size: 20px; }    /* элементы с class="note" */
#price  { font-weight: bold; }  /* элемент с id="price" */
```
Если два правила спорят, побеждает более точный селектор (id сильнее класса, класс сильнее тега),
а при равенстве — правило, написанное ниже.

## Частые ошибки
- Не закрыт парный тег — страница «поедет». Приложение предупреждает.
- Забыта точка или решётка в селекторе: `price { … }` ищет тег `<price>`, а не id.
- Нет `;` между свойствами — следующее свойство не применится.
- Картинка без `alt`.
