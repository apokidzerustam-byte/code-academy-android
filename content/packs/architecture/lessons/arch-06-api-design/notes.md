# Проектирование API

## Адреса и методы

| Метод | Что делает | Идемпотентен |
|---|---|---|
| GET | читает | да |
| POST | создаёт | нет |
| PUT | заменяет целиком | да |
| PATCH | меняет часть | обычно нет |
| DELETE | удаляет | да |

- адрес — **существительное во множественном числе**: `/users`, `/users/42`, `/users/42/orders`;
- не глубже двух уровней вложенности;
- действия выражаются методом, а не глаголом в адресе.

## Коды ответа

`200` успех · `201` создано · `204` успех без тела · `400` плохой запрос · `401` не авторизован · `403` запрещено · `404` не найдено · `405` метод не разрешён · `422` данные не прошли проверку · `500` ошибка сервера.

## Списки

`GET /orders?status=done&sort=-price&page=2&limit=20` — фильтр, сортировка (минус — по убыванию), страница и размер. Размер страницы всегда ограничивают сверху.

## Ошибки

Единый формат:

```py
{"error": {"status": 404, "code": "not_found", "message": "Пользователь не найден"}}
```

Без трассировок, запросов к базе и путей к файлам: подробности — в журнал.

## Версии

Добавлять поля можно. Удалять, переименовывать, менять тип — только в новой версии (`/v2/...`).
