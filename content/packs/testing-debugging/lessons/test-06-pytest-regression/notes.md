# Pytest-стиль, интеграционные и регрессионные тесты

## Пирамида тестов

| Уровень | Что проверяет | Сколько |
|---|---|---|
| Юнит | одну функцию | много, быстрые |
| Интеграционные | несколько частей вместе | меньше |
| Сквозные (E2E) | программу целиком, как пользователь | мало, медленные |

## Стиль pytest

Тест — обычная функция с именем `test_…`, проверка — обычный `assert`. Библиотека pytest находит такие функции сама. На телефоне pytest недоступен, поэтому в уроке используется маленький запускатель с тем же принципом (в обычном проекте достаточно команды `pytest`).

```py
def test_add_positive():
    assert add(2, 3) == 5
```

## Таблица случаев

В pytest для этого есть `@pytest.mark.parametrize`, а в обычном Python — цикл:

```py
def test_is_even():
    for value, expected in [(0, True), (1, False), (2, True), (-3, False)]:
        assert is_even(value) == expected
```

## Регрессионный тест

1. Воспроизвести ошибку тестом — он падает.
2. Исправить код — тест проходит.
3. Оставить тест в проекте навсегда.

## Признаки хорошего теста

- понятное имя;
- одна идея в тесте;
- независимость от других тестов;
- без настоящего времени, сети и случайности (моки);
- быстрый.

Прошедший тест не доказывает, что код верен: он говорит лишь, что в этой точке ошибки не нашли.
