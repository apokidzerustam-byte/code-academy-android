# Граничные случаи

```python
def discount(total):
    if total >= 5000:
        return 10
    if total >= 1000:
        return 5
    return 0
```

Тестовые значения: 999, 1000, 4999, 5000 — по обе стороны каждой границы.

## Чек-лист

1. Границы диапазона и значения рядом: −1, 0, +1.
2. Классы эквивалентности: по одному представителю от каждого.
3. Особые значения: `0`, отрицательные, `""`, `[]`, один элемент, повторы.
4. Свойства результата: длина, порядок, сумма.

## Запомните

Ошибка `>` вместо `>=` не видна на «обычных» данных — только на границе.
