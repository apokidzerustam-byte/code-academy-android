# Первый репозиторий

```bash
pwd                        # где я
git init                   # создать репозиторий
echo "# Мой проект" > README.md
git status                 # что изменилось
git add README.md          # подготовить к сохранению
git commit -m "Первый коммит"
git log --oneline          # история
```

## Состояния файла

| Статус (`git status -s`) | Значение |
|---|---|
| `??` | неотслеживаемый файл |
| `A ` | добавлен в индекс |
| ` M` | изменён, не в индексе |
| `M ` | изменён и в индексе |

## Запомните

1. Цикл работы: изменить → статус → `git add` → `git commit`.
2. Сообщение коммита отвечает на вопрос «что и зачем изменено».
3. Папку `.git` удалять нельзя — в ней вся история.
