## Запомните

1. Пароли, токены и ключи не хранят в репозитории — даже в закрытом.
2. Если секрет уже закоммичен, его нужно **заменить**: удаление из истории не гарантирует безопасность.
3. Сообщение коммита — по делу и в повелительном наклонении.
