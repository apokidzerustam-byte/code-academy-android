# Скрипты и запуск программ

```bash
printf '#!/bin/bash\nname="Анна"\necho "Привет, $name!"\n' > hello.sh
chmod +x hello.sh      # право на исполнение
./hello.sh             # запуск
echo $?                # код возврата: 0 — успех
python3 -c "print(2 + 3)"
python3 app.py
```

## Запомните

1. Первая строка — шебанг `#!/bin/bash`.
2. Переменную присваивают без пробелов: `name="Анна"`.
3. `$name` — подстановка значения.
4. Код возврата 0 — успех, остальные — ошибка.
