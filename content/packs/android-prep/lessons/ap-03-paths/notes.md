# Пути

```bash
mkdir -p school/math school/art   # цепочка папок
ls -R school                      # всё дерево
cd /home/user/project/school      # абсолютный путь
cd ../art                         # относительный: на уровень вверх, затем art
cd ~                              # домашняя папка
cd /                              # корень
```

| Запись | Значение |
|---|---|
| `.` | текущая папка |
| `..` | родительская |
| `~` | домашняя |
| `/` | корень |
