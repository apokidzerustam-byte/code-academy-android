# Первые команды терминала

```bash
pwd                      # где я
mkdir notes              # создать папку
ls                       # что здесь лежит
cd notes                 # войти в папку
cd ..                    # подняться на уровень вверх
echo "Привет" > hello.txt   # записать текст в файл
cat hello.txt            # показать файл
```

## Запомните

1. Молчание команды — обычно успех.
2. `..` — родительская папка, `cd` без аргументов — домашняя.
3. Знак `>` перезаписывает файл целиком.
