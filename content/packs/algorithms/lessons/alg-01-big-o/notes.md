# Сложность алгоритмов: Big O

Скорость алгоритма измеряют **числом шагов** в зависимости от размера данных `n`, а не секундами.

```python
def linear(n):
    steps = 0
    for i in range(n):
        steps += 1
    return steps

print(linear(10), linear(100), linear(1000))   # 10 100 1000
```

## Основные виды роста

| Запись | Название | Пример |
| --- | --- | --- |
| `O(1)` | постоянное | взять `items[0]`, найти ключ в словаре |
| `O(log n)` | логарифмическое | деление данных пополам на каждом шаге |
| `O(n)` | линейное | один проход по списку |
| `O(n²)` | квадратичное | цикл в цикле по одним данным |

```python
def quadratic(n):
    steps = 0
    for i in range(n):
        for j in range(n):
            steps += 1
    return steps

def halving(n):
    steps = 0
    while n > 1:
        n = n // 2
        steps += 1
    return steps

print(quadratic(10), quadratic(100))          # 100 10000
print(halving(10), halving(1000), halving(1000000))   # 3 9 19
```

## Два правила

1. **Константы отбрасываются:** два цикла подряд — `2n`, это всё равно `O(n)`.
2. **Остаётся главное слагаемое:** `n² + n` — это `O(n²)`.

## Запомните

- Big O — про рост на больших данных, а не про точное время.
- Вложенные циклы по одним данным — сигнал о `O(n²)`.
- Деление данных пополам даёт `O(log n)` — очень быстро.
