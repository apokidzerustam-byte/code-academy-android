# Ограничение частоты и минимальные привилегии

## Ограничение частоты

Для каждого ключа (адрес, имя, ключ API) хранят времена последних запросов. Запрос разрешён, если в окне их меньше лимита.

```py
recent = [t for t in hits if now - t < window]
allowed = len(recent) < limit
```

Время передавайте параметром (`now`): так функцию легко проверить, как в уроке про моки.

При отказе: `429 Too Many Requests` и заголовок `Retry-After` (секунды).

| Ключ | Недостаток |
|---|---|
| адрес клиента | за одним адресом — много людей |
| имя учётной записи | жертву можно заблокировать |

Комбинируйте оба и увеличивайте паузу, а не блокируйте навсегда.

## Минимальные привилегии

- **список разрешённого**, запрет по умолчанию;
- роль получает только нужные действия;
- токены: узкие области (`read:orders`, `write:*`) и срок жизни;
- база: у приложения нет права удалять таблицы;
- Android: только нужные разрешения.

Забыть выдать право безопаснее, чем забыть отобрать.
