# Модель угроз и принципы

```python
threats = {"кража телефона": (2, 3), "подбор пароля": (3, 3)}
for name, (probability, impact) in threats.items():
    print(name, probability * impact)
```

Риск = вероятность × ущерб.

## Принципы

1. **Наименьшие привилегии** — только необходимый доступ.
2. **Многослойная защита** — несколько рубежей.
3. **Недоверие к входным данным** — проверяйте всё извне.
4. **Запрещено всё, что не разрешено явно.**

## Белый список вместо чёрного

```python
import re

def valid_username(name):
    return re.fullmatch(r"[a-z0-9_]{3,20}", name) is not None
```

Правила обучения: все примеры курса — в замкнутой песочнице; уязвимости разбираются для защиты своего кода.
