# Переменные

**Переменная** — имя, под которым программа хранит значение.

## Создание и вывод

```python
name = "Аня"      # переменной name присвоили строку
print(name)       # Аня — значение переменной
print("name")     # name — просто текст в кавычках
```

`=` — это **присваивание**, а не сравнение: «положи значение справа в переменную слева».

## Изменение значения

```python
age = 25
print(age)   # 25
age = 26
print(age)   # 26 — старое значение заменено
```

## Несколько значений в print

```python
name = "Аня"
print("Меня зовут", name)   # Меня зовут Аня — пробел ставится сам
```

## Вычисления

```python
price = 120
count = 3
total = price * count   # * — умножение
print(total)            # 360
```

## Правила имён

| Можно | Нельзя | Почему |
| --- | --- | --- |
| `user_name` | `user name` | пробел внутри имени |
| `total2` | `2total` | имя не может начинаться с цифры |
| `price` | `Price` вместо `price` | большие и маленькие буквы различаются |

## Если появилась ошибка

`NameError: name '...' is not defined` — такой переменной нет: опечатка в имени, другая буква в регистре
или переменная создаётся ниже, чем используется.

## Запомните

1. `имя = значение` — присваивание.
2. Текст — в кавычках, числа — без.
3. В переменной хранится последнее присвоенное значение.
