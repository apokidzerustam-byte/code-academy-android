# Логические операторы and, or, not

| Выражение | Истинно, когда |
| --- | --- |
| `a and b` | истинны **обе** части |
| `a or b` | истинна **хотя бы одна** |
| `not a` | `a` ложно |

```python
age = 18
has_ticket = True
print(age >= 16 and has_ticket)   # True
print(False or True)              # True
print(not True)                   # False
```

## Промежуток

```python
x = 15
print(1 <= x <= 10)        # False — короткая запись
print(x >= 1 and x <= 10)  # то же самое
```

## Ложные значения

Пустая строка `""`, число `0` и `False` в условии считаются ложью:

```python
name = ""
if not name:
    print("Введите имя")
```

## Вложенные условия

```python
n = 12
if n > 0:
    if n % 2 == 0:
        print("положительное и чётное")
```

## Запомните

1. `and` — оба условия, `or` — хотя бы одно.
2. `1 <= x <= 10` — проверка промежутка.
3. Каждый уровень вложенности — ещё 4 пробела отступа.
