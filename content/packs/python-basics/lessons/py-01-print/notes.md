# Первая программа: функция print

**Программа** — список команд, которые компьютер выполняет по порядку, сверху вниз.

## Вывод на экран

```python
print("Привет, мир!")
```

- `print` — функция вывода, пишется маленькими буквами.
- В скобках — то, что нужно вывести.
- Текст берут в **кавычки** (`"…"` или `'…'`). Сами кавычки на экран не выводятся.
- Каждый вызов `print` выводит текст с новой строки.

## Текст и числа

```python
print(2 + 3)     # 5      — Python посчитал выражение
print("2 + 3")   # 2 + 3  — это просто текст
```

## Если появилась ошибка

| Сообщение | Что значит | Что делать |
| --- | --- | --- |
| `SyntaxError` | Программа записана не по правилам | Проверьте кавычки и скобки в указанной строке |
| `NameError: name 'Print' is not defined` | Python не знает такого имени | Проверьте регистр: `print`, а не `Print`; текст — в кавычках |

## Запомните
1. `print(...)` выводит на экран.
2. Текст — в кавычках, выражения — без.
3. Номер строки в сообщении об ошибке подсказывает, где искать.
