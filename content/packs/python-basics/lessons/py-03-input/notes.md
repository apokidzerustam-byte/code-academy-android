# Ввод данных: input и строки

`input()` останавливает программу, ждёт ввода и возвращает введённый **текст** (строку).

## Ввод и подсказка

```python
# name = input("Как вас зовут? ")   — программа ждёт ввода
name = "Мария"                       # для примера подставим значение сами
print("Привет,", name)               # Привет, Мария
```

## Склеивание строк

```python
city = "Краков"
print("Я живу в городе" + " " + city)   # пробел добавляем вручную
```

## f-строки

```python
name = "Мария"
city = "Гданьск"
print(f"{name} живёт в городе {city}")   # Мария живёт в городе Гданьск
```

## Ловушка: input возвращает текст

```python
a = "5"          # так выглядит результат input(), если ввели 5
print(a + "1")   # 51 — склеились две строки, а не сложились числа
```

`a + 1` для строки `a` даёт ошибку `TypeError: can only concatenate str (not "int") to str`.

## Запомните

1. `input()` всегда возвращает строку.
2. `+` для строк — склеивание без пробела.
3. f-строка: `f"... {переменная} ..."`.
