# Числа и арифметика

`int` — целые числа (`5`, `-3`), `float` — дробные (`2.5`, точка вместо запятой).

## Действия

| Знак | Действие | Пример | Результат |
| --- | --- | --- | --- |
| `+` | сложение | `7 + 2` | `9` |
| `-` | вычитание | `7 - 2` | `5` |
| `*` | умножение | `7 * 2` | `14` |
| `/` | деление (всегда дробь) | `7 / 2` | `3.5` |
| `//` | целая часть | `7 // 2` | `3` |
| `%` | остаток | `7 % 2` | `1` |
| `**` | степень | `2 ** 10` | `1024` |

```python
print(2 + 3 * 4)     # 14 — сначала умножение
print((2 + 3) * 4)   # 20 — скобки меняют порядок
```

## Текст → число

```python
a = int("12")       # так обрабатывают результат input(): int(input())
b = float("2.5")
print(a + b)        # 14.5
```

`int("пять")` → `ValueError: invalid literal for int() with base 10: 'пять'`.

## Округление

```python
avg = (5 + 4 + 4) / 3
print(round(avg, 2))   # 4.33
```

## Запомните

1. `/` даёт дробь, `//` — целую часть, `%` — остаток.
2. Введённые числа превращают в `int(...)` или `float(...)`.
3. ValueError — строку нельзя превратить в число.
