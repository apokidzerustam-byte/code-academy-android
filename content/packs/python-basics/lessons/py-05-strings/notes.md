# Строки: длина, индексы, срезы, методы

## Длина и индексы

```python
word = "Python"
print(len(word))   # 6
print(word[0])     # P — счёт с нуля
print(word[-1])    # n — последний символ
```

| Символ | P | y | t | h | o | n |
| --- | --- | --- | --- | --- | --- | --- |
| Индекс | 0 | 1 | 2 | 3 | 4 | 5 |
| С конца | -6 | -5 | -4 | -3 | -2 | -1 |

`word[6]` → `IndexError: string index out of range`.

## Срезы

```python
word = "Python"
print(word[0:2])   # Py   — конец не входит
print(word[2:])    # thon — до конца
print(word[:3])    # Pyt  — с начала
```

## Методы

```python
s = "  Привет, мир  "
print(s.upper())                     # все буквы большие
print(s.strip())                     # без пробелов по краям
print(s.strip().replace("мир", "Python"))
print("ПРИВЕТ".lower())              # привет
```

Методы возвращают **новую** строку: `s = s.upper()` — сохраняем результат.

## Запомните

1. Индексы с нуля, `-1` — последний символ.
2. В срезе `[a:b]` символ с индексом `b` не входит.
3. Результат метода нужно сохранить в переменную.
