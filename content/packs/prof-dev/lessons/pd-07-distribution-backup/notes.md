# Распространение и резервное копирование

## Контрольная сумма

```python
import hashlib

data = b"release build"
digest = hashlib.sha256(data).hexdigest()
print(len(digest))
print(digest == hashlib.sha256(data).hexdigest())
```

- один и тот же файл даёт один и тот же хеш, изменённый — другой;
- сравнивайте всю строку, без пробелов и без учёта регистра;
- хеш защищает от порчи, а подпись приложения — от подмены издателя.

## Установка из незнакомых источников

Разрешение выдавайте только нужному источнику и на время установки. Не ставьте APK по ссылкам из чатов.

## Резервные копии

Правило **3-2-1**: три копии, два вида носителей, одна копия в другом месте.

- имена копий: `prefix-2026-11-15.zip` (дата ГГГГ-ММ-ДД сортируется как текст);
- оставляйте несколько последних копий, остальные удаляйте;
- проверяйте восстановление: сравнивайте хеши файлов;
- ключ подписи: зашифрованная копия в двух местах, отдельно от пароля.
