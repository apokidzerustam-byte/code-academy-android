# Текст, кодировки и файлы

```python
print(ord("A"))        # 65
print(chr(66))         # B
data = "Привет".encode("utf-8")
print(len("Привет"), len(data))   # 6 12
print(data.decode("utf-8"))
```

## Идеи

1. Компьютер хранит числа; знак = номер по таблице Юникода.
2. UTF-8: латиница — 1 байт, кириллица — 2, эмодзи — 4.
3. Длина в знаках ≠ размер в байтах.
4. Кодировку файла указывайте явно: `open(..., encoding="utf-8")`.
5. Расширение файла — лишь подсказка; формат определяет структуру байтов.
