# Как устроен компьютер

| Часть | Роль |
|---|---|
| Процессор | выполняет команды |
| Оперативная память | быстрая, рабочие данные, теряется при выключении |
| Накопитель | медленнее, хранит постоянно |
| Операционная система | управляет ресурсами и запускает программы |

## Размеры

```python
kb = 1024
mb = 1024 * kb
gb = 1024 * mb
print(kb, mb, gb)
```

Программа — файл на накопителе. Процесс — запущенная программа.
