# Алгоритмы и исходный код

```python
def biggest(a, b, c):
    best = a
    if b > best:
        best = b
    if c > best:
        best = c
    return best

print(biggest(3, 9, 5))
```

## Основные конструкции

1. Последовательность — шаги подряд.
2. Условие — `if`.
3. Повторение — `for`, `while`.

## Идеи

- Алгоритм конечен, шаги однозначны.
- Компилятор переводит заранее (Kotlin), интерпретатор — по ходу (Python).
- Сначала идея словами (псевдокод), потом код.
