# Двоичная система

```python
print(int("1011", 2))    # 11
print(bin(26))           # 0b11010
print(format(5, "08b"))  # 00000101
print(2 ** 8)            # 256
print(hex(255))          # 0xff
```

| Двоичное | Десятичное |
|---|---|
| 0001 | 1 |
| 0010 | 2 |
| 0100 | 4 |
| 1000 | 8 |

Позиции — степени двойки: 1, 2, 4, 8, 16, … В n битах — 2ⁿ значений.
